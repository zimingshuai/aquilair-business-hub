# 数据交付规范（齐套诊断可视化）

> 适用：一切呈现查询所得数据的回答——六类齐套总览、子项进度、物料缺口、到货跟踪、计划清单、风险明细等。
> 豁免：仅元数据解释（规则/字段口径）、确认卡、无数据明细的纯结论/待核查说明。
> 本规范为 Aquilair data-delivery 规范在新品上市域的内化版（2026-10-28 升级：输出强制可视化，按数据复杂度分级路由；渲染协议按宿主分支落地。2026-10-29 修订：**简单档新增 HTML 静态看板落档**——两档交付均须落档）。

## 铁律

1. **只回纯 Markdown 文本表格 = 违规**：凡呈现查询所得数据必须配可视化——表格只展示瓶颈与时间窗，用户靠图才能一眼看到问题；表格仅作明细附表，不能替代图。
2. 图表**不得歪曲数据**：坐标从合理基线开始、占比用整体=100% 的图、数值标注与数据源一致。
3. 图上数值与正文/表格数值必须一致（同一数据只算一次，处处同值）。
4. 数据来源必须在交付物中标明（实体/查询 + 时间口径；模拟时间轴注明 current_date 基准）。
5. 展示层计算（缺口相减、合计）注明口径并复核一致。

## 复杂度判定（先判复杂度，再选形态）

- **简单数据**：分类 ≤ 6、单指标或双指标、一次性对比、无需筛选/下钻——如六类状态总览、子项通过率、简单对比。
- **复杂数据**：多指标多维度（跨仓/跨 SKU 缺口矩阵、多订单到货跟踪、采购方案多维度对比）、需筛选/下钻/联动探查、或任一维度分类超过 6 个。
- 判定先于出图；拿不准时按复杂处理（复杂覆盖简单能力，宁可多做一次落档）。

## 渲染路由（两档，按复杂度选一；协议按宿主分支落地）

| 数据复杂度 | 形态 | 要求 |
| --- | --- | --- |
| 简单 | **多图图表组 + 静态看板落档** | 2~4 张独立图表（如 ① 状态总览条形/占比 ② 时间轴倒排甘特 ③ 缺口/对比条形），每图数值与正文一致、不硬编码颜色；**另产自包含单文件 HTML 静态看板落档**（内联 CSS/脚本、无外部依赖、静态首屏完整可读）→ `deliverables/` |
| 复杂 | **交互看板 + 落档 + 数值图** | ① 对话内交互看板（静态首屏可读 + 筛选/下钻/联动）② 自包含 HTML（内联 CSS/脚本、无外部依赖）落档 `deliverables/`（文件名含场景与数据口径日期）③ 另配图表承载精确数值 |

- 看板/图表与落档 HTML 用**同一份数据、同一口径**；落档页脚注明数据来源与生成日。
- 无论哪档：交付时先给 3~5 行结论先行摘要，看板不能替代结论。
- 语义色约定（看板/落档通用）：绿=已齐套 红=不通过 黄=待核查。

## 宿主渲染分支（同一规范，两套协议）

- **Doubao Work 宿主**（2026-10-28 实测挂载）：渲染前必须 Read `doubao-visualization/SKILL.md`，不向用户解释渲染链、直接选型出图——简单档走 **echarts 模式**（每个图一个 ```echarts option 代码块，自包含；追加读 `references/mode-echarts.md`，电脑端再读 `echarts-web-pc-spec.md`）**+ `html` 技能手写自包含 HTML 静态看板落档**；复杂档走 **html_svg 模式**（对话内 ```html type="renderer" 块，读 `references/mode-html-svg.md`）+ `html` 技能手写自包含 HTML 落档 + echarts 精确数值图。
- **ZCode 宿主**：多图/看板均以自包含单文件 HTML 交付（内联 CSS/SVG/内嵌脚本，无 CDN 依赖），写入工作区 `deliverables/` 并在对话中给出文件路径链接；对话内可配合官方 visualize/Gen UI 能力渲染交互视图，但**落档文件不可省略**。

## 场景与图型对照

| 交付场景 | 复杂度 | 推荐形态 |
| --- | --- | --- |
| 六类齐套状态总览 | 简单 | 状态条形（子项通过/未通过 + 通过率标签）+ 时间轴甘特（计划 vs 实际 + 当前日/就绪日/上市日竖线） |
| 齐套时间倒排 | 简单 | 时间轴泳道/甘特 + 里程碑竖线（超窗与瓶颈标注） |
| 物料缺口（单计划汇总） | 简单 | 毛需求 vs 总齐套量分组条形，缺口段高亮 |
| 物料缺口（跨仓/跨 SKU） | 复杂 | 交互看板（仓库/SKU 筛选 + 缺口下钻）→ 落档 → 精确数值图 |
| 到货跟踪（多订单） | 复杂 | 交互看板（订单进度 + 超期高亮 + 状态筛选）→ 落档 → 数值图 |
| 采购方案对比 | 复杂 | 交互看板（多维度对比 + 联动）→ 落档 → 数值图 |

> 简单档场景（上表前三行）同样须 HTML 静态看板落档（2026-10-29 修订）——「简单→只出图不落档」的旧表述作废。

## 命名与路径

- 落档文件名含场景与数据口径日期：如 `齐套看板-青提冰茶-2026-11-10.html`（日期用数据内 current_date，生成日另注页脚）。
- 存放于当前工作区约定目录（无约定时建 `deliverables/`）。

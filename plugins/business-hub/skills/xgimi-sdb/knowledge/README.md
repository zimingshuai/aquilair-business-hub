# knowledge（业务知识源）

按技能工厂第 5 步⑤落盘：业务知识源文档以**源件形式**存放（本项目不走 aquilair-knowledge-wiki 摄取，2026-10-23 用户裁决），references 引用口径时逐条标注出处。

**纪律（2026-11-04 用户规范）**：技能包内**不得存放任何演示数据**——案例文档、预期结果、实测数字实例、批次/物料/订单实例一律不进本技能；它们存放在模型仓库 `demo/`（演示案例与 `skill-archive/` 归档）。技能只保留方法论、契约、铁律与占位符。

## 纪律

- 状态/挂账只进 `STATUS.md`，且必须带解除条件；解除时按其「挂账生命周期」联扫全仓。
- 数字正确性靠勾稽自洽（chain-playbook §4），不靠与任何文档/基线数字比对；**任何文档里的具体数字都不作预期值**。
- references 与 SKILL.md 中的口径须可追溯到上表某文件或 FACT-CARDS 编号；新增/更新源文档同步更新本清单。

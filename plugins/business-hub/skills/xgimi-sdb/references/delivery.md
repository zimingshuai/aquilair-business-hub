# 数据交付可视化规范（极米供需平衡域）

> 适用：一切呈现查询/测算所得数据的交付物——差异清单、影响概览、需求概览、缺口概览、四世界对比看板、风险清单、方案对比、采购计划汇总等。
> 豁免：确认卡、口径/规则解释、无数据明细的纯结论或异常说明、卡间内务核对。
> 出处：Aquilair data-delivery 规范在极米域的内化版。

## 铁律

1. **只回纯 Markdown 文本表格 = 违规**：凡呈现查询/测算数据必须配可视化；表格仅作明细附表。
2. 图不歪曲数据：数值条形从合理基线（供需类从 0 起）、占比整体=100%、图上标注与数据源逐值一致。
3. 同一数据只算一次、处处同值；展示层计算注明口径（如「由 N 行差异行计数」）并复核一致。
4. 数据来源必须在交付物标明：实体/查询＋批次号＋分支名（沙箱数据必注分支）＋时间口径。
5. 结论先行：交付物开头 3~5 行结论摘要，图不能替代结论。

## 复杂度判定（先判定再选型；拿不准按复杂处理）

- **简单**：分类 ≤6、单/双指标、一次性对比、无需筛选下钻——差异类型分布、单成品影响概览、需求概览、批次级风险汇总 → **echarts 多图**（2~4 个独立 option）。
- **复杂**：多指标多维度（缺口矩阵、四世界 × 8 维对比、多订单跟踪、多物料采购计划）、需筛选/下钻/联动 → **html_svg 交互看板落档＋echarts 精确数值图**。

## 模板化生成（不从零手写，速度与正确性双保险）

- **echarts**：套用下方 §骨架，只替换 `title`、类目/数值数组、轴名称，不改 option 结构、不硬编码颜色。
- **html_svg 看板**：复制 [`references/dashboard-template.html`](references/dashboard-template.html)，**只替换文件头 `DATA` 区**（metrics/groups/source）与标题——维度切换、下钻高亮、配色模板已内置；落档 `deliverables/<场景>-<产品>-<批次/日期>.html`（自包含、无外部依赖，页脚注明数据来源与生成日）。
- 看板与 echarts 图用同一份数据、同一口径。
- 宿主适配：**Doubao Work** 渲染前读 doubao-visualization SKILL.md 及对应 mode 文件；**ZCode** 用宿主可视化能力并落会话可视化目录。
- 语义色约定：绿=供需平衡 红=缺口（交付风险） 黄=呆滞/待处置 灰=未执行。

## 场景与图型对照

| 交付场景 | 复杂度 | 形态 |
| --- | --- | --- |
| 卡① 差异清单（六类） | 简单 | echarts 骨架 A：差异类型分布条形 |
| 卡② 影响概览 | 简单 | echarts 骨架 A：变化物料影响条形，繁杂度随结论文字给出 |
| 卡③ 需求概览 | 简单 | echarts 骨架 A：每物料毛需求条形（降序） |
| 卡④ 缺口概览 | 物料 ≤6 简单；>6 复杂 | 简单：骨架 B 分组条形（毛需求/已分配/剩余缺口，缺口段高亮）；复杂：看板模板 → 落档 → echarts |
| 四世界对比看板（2×2 × 8 维） | 复杂 | 看板模板（世界/维度切换）→ 落档 → echarts 骨架 B |
| 风险清单（呆滞+缺口，金额降序） | 复杂 | 看板模板（类型/物料筛选）→ 落档 → echarts |
| 方案对比（多方案 × 多维） | 复杂 | 看板模板 → 落档 → echarts 骨架 B |
| 采购计划汇总 | 物料少=简单；多=复杂 | 简单：骨架 A（建议采购量，标注待审批）；复杂：看板模板 → 落档 → echarts |

## echarts 骨架 A（单指标条形）

```javascript
{
  title: { text: "<标题>" },
  tooltip: {},
  xAxis: { type: "category", data: ["<类目1>", "<类目2>"] },
  yAxis: { type: "value" },
  series: [{ type: "bar", data: [100, 200], label: { show: true, position: "top" } }]
}
```

## echarts 骨架 B（多系列分组条形）

```javascript
{
  title: { text: "<标题>" },
  tooltip: { trigger: "axis" },
  legend: {},
  xAxis: { type: "category", data: ["<类目1>", "<类目2>"] },
  yAxis: { type: "value" },
  series: [
    { name: "<系列1>", type: "bar", data: [10, 20] },
    { name: "<系列2>", type: "bar", data: [30, 40] }
  ]
}
```

# 计划与预测剧本

> 适用问题：最近的新品上市计划、计划总览、参考品与历史销量、首月能卖多少、预测口径、分周需求、计划对比。
> 前置：已锁定唯一上市计划（歧义先列候选）；预测数值一律引用规则回写值，本剧本不含任何自算。

## 场景对照

| 用户问法 | 路径 |
| --- | --- |
| 最近的新品上市计划是什么？ | 全量 NewDishLaunchPlan → 按状态锁定唯一「执行中」计划（其余「已完成」为历史/参考品计划）→ 总览表 + T-N（数据内 current_date 基准）→ 建议下一步检查维度 |
| 参考品是什么/历史卖得怎么样 | 计划 objects_links → 上市新品（Dish）/ 参考品绑定（ReferenceDishBinding，含全套系数）/ 参考品上市计划（NP001 首月实销 269,693、周拆分） |
| 首月能卖多少杯 | 引用 forecast_first_month_sales_qty（规则回写）+ 因子链表（见下）+ 口径提醒与数据限制 |
| 需求怎么拆的/分周需求 | ForecastSalesDemand + MaterialDemand 的 dish_demand（注意：实测仅 1 条（第 4 周 60,108 杯），4 条周拆分缺 3 条——如实报数据不完整） |

## 计划总览要素（全给）

中文名（编码）｜类型（全新品/季节品）｜计划上市日｜计划就绪日（**双口径**：计划表字段 vs 齐套实体字段，如实并列待业务确认）｜计划开始日（齐套口径）｜门店范围与数量｜首月经营目标 ｜ 需求预测基准值（分列）｜参考品链（参考品+其历史计划）｜计划状态（执行中/已完成）。
脏数据规避：plan_start/end_date 数值序列不直接展示（改用日期字段并注明）；1970 零值时间戳、空串负责人引用前判空。

## 预测因子链模板（引用回写值逐项列出）

| 因子 | 回写值 | 说明 |
| --- | --- | --- |
| 参考品上市实际均店销量 | 898.98 杯/店 | 规则「获取参考品绑定实体的参考品上市实际均店销量」 |
| × 参考品季节系数 | 0.867 | 规则回写 |

| = 预测新品首月均店销量 | 2,154.85 杯/店 | 规则「计算参考品绑定实体的预测新品首月均店销量」 |
| × 目标门店 | 300 家 | 量纲复核一致 |

## 口径三分离（最易错点）

1. **首月经营目标**（target_first_month_sales_qty，人工设定，如 300,000 杯）
2. **需求预测基准值**（forecast_first_month_sales_qty，规则回写，如 646,454.121 杯——约为目标 2.15 倍，展示层相除需注明）
3. **分周预测需求**（ForecastSalesDemand / MaterialDemand.dish_demand——注意实测拆分口径与目标一致（4 周合计=300,000），与预测基准值不同源）

三者不得混用；物料/采购测算采用哪个口径需业务确认（当前数据：物料需求按目标口径拆分）。

## 数据限制（预测类回答必附）

- 分周预测仅 1 条（第 4 周），4 条周拆分缺 3 条——影响需求展开完整性；
- 新品未上市，首月实销字段全 0，预测无法用实销校验；
- 【待处理】系数未定稿，基准值口径可能随规则定稿变化。

## 可视化建议

计划总览→总览卡+时间轴；预测→因子链瀑布/条形 + 目标 vs 预测对比；分周→周分布条形。规范见 delivery.md。

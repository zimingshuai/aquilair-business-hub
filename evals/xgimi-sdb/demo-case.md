# POC 演示案例：X20 投影仪 BOM 升级全链路供需平衡

> 案例定位：一个案例跑通全部业务路径（v0.3.0：9 个业务函数，沙箱推演贯穿全程——点检完成后即按决策假设展开多个沙箱，每个沙箱独立走完 计算链，最后并列对比、选定执行。沙箱机制为平台后台能力，模型与函数不含任何沙箱概念）——六类点检差异、多层 BOM 展开、FEFO 供需分配、替代填补、六种风险来源、策略测算（策略库驱动可扩展）、方案组合与采购计划。**本案例同时是函数发布前的测试数据基线**：`_demo_chain_test.py` 用本案例数据串跑 9 个 `@function` 入口并逐项断言「预期结果」列的数字。

## 1. 业务故事

极米 X20 投影仪即将从 BOM V1 升级到 V2（2026-11-01 生效），研发变更单内容：

1. **光源模组 LED-B1 被删除**（改由光机厂整体供料），现有库存与在途将变呆滞；
2. **新增镁合金外壳 MG-CASE** 替代塑胶外壳（塑胶为老机型共用件不在本 BOM），需新开采购；
3. **镜片 LENS-45 单机用量 2 → 1.5**（光效优化），用量缩减产生呆滞；
4. **主控芯片 IC-M9771 单机用量 1 → 2**（新增独立画质处理），产生增量缺口；
5. **散热风扇替代关系调整**：新增替代料 FAN-40S（优先级1、比例1.0）；原替代料 FAN-40A 优先级 1→2、换算比例 1.0→1.2；
6. **电容 CAP-100 的替代关系被删除**（CAP-100T 认证失效），缺口只能采购。

销售端有两笔已确认未交付订单（500 + 300 = **800 台根需求**）。计划员要回答：这次 BOM 升级会造成哪些物料呆滞、哪些缺口、各多少钱，呆滞怎么消化、缺口怎么补，最终形成采购计划。

# 沙箱推演（贯穿式动线，v0.3.0-draft.2）

**沙箱不是独立环节**：点检完成、进入"算物料需求"的时刻，推演即开始——按决策组合展开为多个沙箱（平台后台为每个沙箱复制一份生产数据），每个沙箱内独立走完 需求→分配→替代→风险→策略→方案 全链，证据链分沙箱留存，最后按目标目录并列对比、选定执行。

## 决策矩阵与沙箱（2×2）

| 沙箱 | 替代路径（use_substitute） | 缺口采购（STRAT-PURCHASE 启停） |
|---|---|---|
| 沙箱1 | 按替代优先级（FAN-40S 优先） | 采购 |
| 沙箱2 | 按替代优先级（FAN-40S 优先） | 不采购 |
| 沙箱3 | 不用替代料 | 采购 |
| 沙箱4 | 不用替代料 | 不采购 |

**沙箱间唯一变量 = 这两个决策的取值组合**。策略库的启用基线在建沙箱前于 main 一次性设定，所有沙箱继承同一套——不存在"沙箱自己知道用什么策略"。三种"选策略"时刻：① 建沙箱前配置策略基线（main）；② 建沙箱时定替代路径假设；③ 对比后选定方案。想看不同策略组合的效果 = 改①的配置、重跑。

## 最终对比矩阵（验收口径，实测于 _demo_chain_test.py）

| 目标维度（SupplyDemandObjective 目录行） | 沙箱1 替代+采购 | 沙箱2 替代+不采购 | 沙箱3 不替代+采购 | 沙箱4 不替代+不采购 |
|---|---|---|---|---|
| 按期交付台数 | **800** | 446 | **800** | 446 |
| 延迟交付台数 | 0 | 354 | 0 | 354 |
| 剩余呆滞数量（个，按物料） | LED 550/LENS 712/40A 64 | 同左 | LED 550/LENS 712/**40S 300/40A 400** | 同左 |
| 剩余缺口数量（个，按物料） | 0 | MG 116/IC 716/IC-DP 116/CAP 1264/LENS 336 | FAN-40 580 + 常规缺口 | FAN-40 580 + 全部 |
| 采购金额（元） | 135,020 | 0 | 150,100 | 0 |
| 附带成本（元） | 0 | 0 | 0 | 0 |
| 方案状态 | 已选定→采购计划 5 条 | 候选 | 候选 | 候选 |

要点：不采购世界的交付卡在 IC-M9771（446 台）——**光换替代料救不了交期，缺口采购必须打开**；替代的价值 = 呆滞少 1.9 万 + FAN-40 采购省 1.5 万；混合路径（S 尽 A 补）呆滞最小但消耗全部高端 S 库存——业务权衡留给人。

## 交付影响呈现（A16 口径）

按物料齐套时间线：各物料"现有库存（即期）+ 在途（PO 到货日）+ 采购（下单+供货周期）"对着订单交期（SO-101 500 台@11-30、SO-102 300 台@12-15）取最小可交付台数。**按物料明细+关联订单在方案目标值明细行下钻**，不做单一汇总台数列（避免公共短缺掩蔽替代选择的影响）。

## 沙箱假设的传递

use_substitute 参数（ALL/NONE）注入 substitute_fill 与 strategy_simulate；采购维度 = 策略库 STRAT-PURCHASE 的 is_active（沙箱内数据开关）。沙箱内 BOMAlter 数据保持原样，保证呆滞归因完整。

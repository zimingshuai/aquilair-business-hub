## 失败明细与根因

### ddl-001(2/3 ⚠️)

- **r2 失败点**:四段式其余要素全部合规(口径四要素齐全、pillow 直绘 PNG 横向条形图、明细表中文名称(编码)、洞察落到建议动作),但主结论段(「③ 结论先行」)排在「② 风险总览图」**之后**,违反 expected「结论在图之前」。r1/r3 均结论先行开头。
- 根因方向:SKILL.md 第三节「先结论 → 后证据」与四段式(口径→图→明细→洞察)并置,模型偶发把「结论」实现为四段中的第③段而非全文开头的结论段——**措辞位置歧义**,非能力缺失。

### ddl-006(1/3 ❌)

- **r1/r3 共同失败点**(r2 全部达成):①明细表**缺 ABC 分类列**(expected 明确要求);②洞察**未区分「周转慢=超储」与「周转快但缺货」两类处置**——Top10 第 8 名淡奶油1L(SKU004)@苏州区域仓(WH002)在库仅 20、系统供需匹配为「库存缺货」,是榜单中唯一"不该压库存反而需补货"的反向条目,r2 专门用红描边标出并单列处置建议,r1/r3 均未识别。
- 根因方向:**两个失败点在 SKILL.md 中均无显式措辞支撑**——fnb SKILL.md 无「Top N 明细须含 ABC 分类」要求,ddl SKILL.md 选型表仅有「Top N → 横向条形图」而无两类处置洞察要求。expected 比规范严格,属**用例与规范的对齐缺口**,非单纯行为违规。

## 判定说明(通道受限 vs 行为违规,工作令第 5 条)

- 全部 15 个应配图采样(ddl-001/002/003/006/007 及 ddl-008 段2)无一因通道问题放弃配图——子代理均在 matplotlib 失败后不改全局环境、按 Playbook 等价映射表转 HTML 看板/SVG/PIL 交付。**零例「工具不可达」被误判为「行为违规」**,「通道受限下的最大合规」成立。
- 豁免用例(ddl-004 ×3、ddl-005 ×3)全部零图且保留结论段,证明子代理并非无脑配图,豁免边界双向工作正常——ddl-005 作为环境反向对照有效。
- 实际交付形态分布:plotly 离线 HTML 看板(内嵌 JS)×7、PIL 直绘 PNG ×4、纯 Python SVG ×3、HTML+内联 SVG ×1。

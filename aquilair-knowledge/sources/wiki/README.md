# wiki 域源文档（knowledge-wiki 技能自举域）

`aquilair-knowledge-wiki` 技能自身的**设计思想源域**：该技能吸收的原始构想文档落位于此（摄取流程与本技能管理业务域完全一致——自举示范）。

## purpose（本域为什么存在）

- **关键问题**：知识库技能自身的设计依据——对标对象的思想源头、已吸收/未吸收清单、每轮吸收的变更记录。
- **研究范围**：Karpathy LLM Wiki 及其社区实现的模式与实战教训（gist 正文与评论区、nashsu/balukosuri 两个实现）。
- **演进论点**：吸收看适用性不看完整度——单域场景的结构（类型分目录、向量检索、Obsidian 生态）不照搬，工程纪律（写时矛盾、无来源即发现、教训放必读处、事件驱动巡检）持续吸收。

**当前源文档**：[`raw/llm-wiki.md`](raw/llm-wiki.md)（英文原文）与 [`raw/llm-wiki.zh.md`](raw/llm-wiki.zh.md)（中文译本，2026-09-28 落位）——Karpathy《LLM Wiki》原始构想（来自 [balukosuri/llm-wiki-karpathy](https://github.com/balukosuri/llm-wiki-karpathy)，2026-09-28 由用户提供 ingest；raw 层只读不改，中文版以译本并列提供）。二次调研与「为什么不收编原仓库」的决策记录见 `aquilair-knowledge/research/2026-09-28-llm-wiki-karpathy.md`。
